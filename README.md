# HILEX Digital — Africa Digital Economy Mission Hub

**Mission:** EDUCATE → CONNECT → BUILD → ADOPT → EMPOWER

HILEX Digital is an independent educational/community gateway focused on Africa's evolving digital economy: blockchain, digital assets, Web3, digital finance, regulation, Pi and practical business participation.

## v3 foundation

This version is intentionally a clean static GitHub Pages foundation. It uses ordinary HTML, CSS and JavaScript — no Render hosting and no build system.

### Structure

- `index.html` — main HILEX Digital homepage
- `404.html` — custom not-found page
- `css/style.css` — site styling
- `js/app.js` — navigation, mobile menu and language selector
- `languages/` — current interface-language files
- `content/education/` — four starter education modules
- `content/pi/index.html` — Pi resource directory
- `content/business/index.html` — business resources
- `content/regulation/index.html` — regulation watch
- `content/africa/index.html` — Africa mission
- `news/index.html` — digital-economy news standards
- `CNAME` — HILEX custom domain

## Current interface languages

English, French, Portuguese, Kiswahili, Shona, isiZulu, Bemba and Chichewa.

The structure is ready for additional African languages later.

## Important safety and independence notice

HILEX is an independent educational/community project. External websites and community projects linked from HILEX are not automatically verified, endorsed or guaranteed by HILEX.

Never publish or store a wallet recovery phrase, private key, password, API secret or verification code in this repository. Never give such credentials to another person.

For Pi-related information, use official Pi Network domains and verify URLs carefully.

## GitHub Pages

Publish from:
- Branch: `main`
- Folder: `/ (root)`

The custom domain is:

`hilexdigital.co.zw`

Keep the `CNAME` file in the root of the publishing source. GitHub Pages also requires the custom domain to be configured in the repository's **Settings → Pages** area.

DNS is configured at the domain registrar/DNS provider, not inside this repository. GitHub's current documentation recommends the appropriate apex-domain DNS records and supports HTTPS for correctly configured custom domains.
