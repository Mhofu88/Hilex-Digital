Understanding Pi Network

Independent HILEX education. Verify current Pi-specific instructions through official Pi Network sources.

Pi Network is a blockchain ecosystem with a mobile Pi app, Pi Browser, a non-custodial wallet, Mainnet blockchain and applications built for its ecosystem. HILEX treats these components separately so beginners can understand what each one does.

Official-source rule: Product behaviour, eligibility requirements and ecosystem policies can change. Use Pi Network's official website and documentation for the latest instructions.

The Pi app

The Pi app is the account and community entry point used by Pioneers.

Pi Browser

Pi Browser is the environment through which users can access official Pi products and ecosystem applications. Pi developers also use Pi Browser capabilities for authentication and payments.

Pi Wallet

The Pi Wallet is non-custodial. The user is responsible for protecting the wallet passphrase.

Mainnet and ecosystem apps

Mainnet is Pi's live blockchain environment. Ecosystem apps may integrate Pi authentication, payments or other Pi features. An app being available in the ecosystem does not mean it was built by the Pi Core Team.
